# Quiz

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![Windows](https://img.shields.io/badge/Windows-0078D4) ![JSON](https://img.shields.io/badge/JSON-333333?logo=json&logoColor=white)

**Quiz** — простое настольное приложение для Windows на Python и Tkinter. Подготовьте свои вопросы, запустите викторину и посмотрите, сколько ответов оказалось правильными.

## Возможности

- Вопросы с вариантами ответов и полосой прогресса.
- Итоговый результат в баллах и процентах, с разбором каждого ответа.
- Русский (`main.py`) и английский (`main_eng.py`) интерфейсы.

## Запуск

Установите Python 3 и выполните команду в папке проекта в PowerShell.

```powershell
py main.py
```

Для английского интерфейса используйте `py main_eng.py`.

## Свои вопросы

Вопросы, варианты и правильные ответы хранятся в файле `questions.json`. Если файла нет, приложение создаст пример при первом запуске. Откройте его в текстовом редакторе и добавьте свои вопросы по такому шаблону.

```json
[
  {
    "question": "Какая планета ближе всего к Солнцу?",
    "options": ["Венера", "Меркурий", "Марс"],
    "answer": "Меркурий"
  }
]
```

Значение `answer` должно совпадать с одним из вариантов в `options`.
